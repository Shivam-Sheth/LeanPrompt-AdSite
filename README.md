# LeanPrompt — Landing Page

**Grammarly for AI prompts.** A polished, investor-ready single-page website for the LeanPrompt startup (university competition demo). Front-end only—no backend, no LLM APIs. All demos use hardcoded examples and simulated metrics.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
```

Output is in `dist/`. Deploy that folder to any static host (Vercel, Netlify, GitHub Pages, etc.).

## Tech

- React 19 + Vite
- Tailwind CSS v4
- No API calls, no auth, no database
